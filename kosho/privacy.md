# 小姓BOT プライバシーポリシー

制定日：2026年9月29日／最終更新日：2026年10月3日

## 1. 対象と開発状況

本方針は、Discordアプリ「小姓BOT」の運営者（Discordユーザー名 **chimposs**）による情報の取り扱いを定めます。本BOTは、投稿作成・管理、チケット対応、イベント抽選・ビンゴ、サーバー運営支援のために開発中です。

以下には提供予定の機能の運営方針も含まれます。未提供の機能について、そのデータ処理が既に行われていることを示すものではありません。各機能の提供開始前に、実装、保存先、外部連携を本方針と一致させ、必要な情報を追加して案内します。

## 2. 取り扱う情報と目的

利用者が実行した操作と、管理者が有効にした機能に必要な範囲で、次の情報を取り扱います。

| 情報 | 主な目的 |
| --- | --- |
| Discordのユーザー・サーバー・チャンネル・ロール・メッセージのID、表示名、必要な権限情報 | 操作者の識別、権限確認、投稿先の指定、機能の提供 |
| 投稿本文、Embed／Components V2の設定、下書き、テンプレート、画像・添付情報 | 指定された投稿の作成、保存、編集、再利用 |
| 本人またはサーバー管理者が入力するゲーム内の名前、職人・採集・武器・防具・戦力・禅業・備考、DiscordユーザーID、入藩のためのロール、サーバー加入日時、更新時刻・版番号 | 藩士名簿の登録・訂正、閲覧権限の確認、絞り込み・一覧・詳細の表示、退出・再加入時の情報保護 |
| チケットのフォーム回答、本文、参加者、添付情報、担当者、開閉時刻、対応状況 | 問い合わせの受付、担当者への提示、対応管理 |
| 記録機能が有効なチケットのメッセージ・投稿者・日時・添付情報 | 案内した範囲での対応履歴の作成と書き出し |
| イベントの主催者・参加者のDiscord識別情報、表示名・加入日時、主催者が入力した参加者名・景品名、受付・抽選日時、抽選結果、ビンゴカード・抽出順・順位、投稿ID | くじ引き・あみだくじ・ルーレットの抽選、参加受付、ビンゴの自動進行、結果表示、再起動・通信失敗後の継続 |
| サーバー別設定、担当ロール、投稿先、機能の有効・無効 | 管理者が指定した動作の提供 |
| 操作時刻、実行機能、処理結果、必要最小限の識別子・エラー情報 | 障害調査、不正利用対策、運用保守 |

通常の会話を一律に収集・保存することは目的に含みません。取得したDiscordの情報を広告目的で販売したり、AIモデルの学習用データとして提供したりしません。

## 3. チケットの閲覧と記録

チケットは、参加者・指定スタッフ・Discord上の権限を持つサーバー管理者等が閲覧できます。BOT運営者は、問い合わせ対応や障害調査等に必要な場合に限り、運営上アクセスできる情報を確認します。

トランスクリプト（会話履歴の複製）の保存は初期設定で無効とし、有効化する場合は、記録対象・閲覧者・保存先・保存期間をチケット利用者に案内します。書き出し先の権限は、サーバー管理者が確認します。

### 藩士名簿の閲覧と登録

名簿は、管理者が指定した入藩用ロールのいずれかを持つ利用者と「サーバー管理」の権限を持つ利用者に限って表示します。現在の導入先では「戦闘・職人・採集」のいずれかのロールが対象です。コマンドの結果は操作者本人にのみ表示し、チャンネルへ名簿を自動投稿しません。Discordが保持する操作結果のコピーや、閲覧者が保存した情報は、BOTの保存データの削除では消去できません。

本人が自分の情報を登録・更新し、サーバー管理者も対象の情報を修正できます。保存前に閲覧対象を案内し、保存ボタンの操作で登録を確定します。入力は本人または管理者の申告情報として扱い、ゲームとの本人確認やゲーム情報の自動取得は行いません。管理者は本人と確認したゲーム情報のみを入力し、実名・連絡先・秘密情報等を備考へ記載しないでください。

### イベントの参加と閲覧

イベントの受付、参加者名、抽選結果、ビンゴで出た番号・順位は、主催者が指定した投稿先を閲覧できる人に表示します。ビンゴカードは原則として本人にのみ操作結果で表示します。主催者は参加者名や景品名を入力する前に、本人の了解と公開範囲を確認してください。BOTは手入力の名前とDiscordアカウントが同じ人かを自動判定しません。

指定日時に受付・抽選を進め、ビンゴは10秒間隔を目安に同じ投稿を更新します。通信や基盤の遅延がある場合は表示が遅れることがあります。抽選結果とビンゴの抽出順を保存し、再起動や投稿更新の再試行で引き直しません。

## 4. 保存と削除

次の期間は、BOT運営者が管理するデータベースやファイル内の情報に適用します。

- 設定・下書き・テンプレートは機能の利用中に保持し、削除操作、BOTのサーバーからの削除、利用終了等で不要になった場合は速やかに、遅くとも30日以内に削除します。
- 藩士名簿は利用中保持し、本人の `/藩士 削除` または `/データ削除` で、対象の名簿とその編集中データを稼働中のデータベースから削除します。名簿の入力下書き・一覧の操作画面は作成から15分で期限切れとなります。BOTのサーバーからの削除、対象者の退出・再加入を確実に確認した場合にも名簿を削除します。常時運用中は1分ごとに最大3名の保存済み名簿について参加状態を順に確認し、通信・認証の失敗を退出と誤認して削除しません。入藩用ロールや権限を失った人の情報は、新たな閲覧結果に表示しません。停止・権限失効中は削除確認に運営者による復旧が必要です。
- イベントの下書きは作成から15分で期限切れとなります。イベント設定、参加者、結果、ビンゴカード・抽出順・順位はイベント作成から最大30日間保持し、その後削除します。本人の `/データ削除` で参加データとカードを削除し、受付が終了して結果を固定したイベントでは、その人を識別する情報を匿名化して抽選結果を維持します。主催者が自身のデータを削除した場合は、その人が作成したイベントと関連カードも削除します。手入力の名前はアカウントと結びつかないため、主催者または運営者へ訂正・削除を依頼してください。Discord上の投稿は別に管理され、保存データの削除だけでは投稿全体が消去されません。
- 対応中のチケット情報は対応に必要な期間保持します。閉鎖済みのチケット、またはBOTのサーバーからの削除・機能終了により不要になったチケットについては、フォーム回答・担当者・対応状況等の情報と、会話・トランスクリプト・添付ファイルの複製を、その時点から30日以内に削除します。
- 操作・エラーログは記録後30日以内に削除します。本文や秘密情報を不要にログへ記録しません。

運用中のデータベースでは、上記の削除期限を適用します。ホスティング事業者Cloudflareが提供する障害復旧用のデータベース履歴には、削除前の暗号化データが削除後も最大30日間残る場合があります。例えば、終了後30日で運用データから削除するチケット記録は、復旧用履歴には終了後最大60日間残る場合があります。復旧用履歴は通常のBOT機能から参照せず、障害復旧の目的に限って利用します。復旧時には、削除依頼と保存期間を再確認し、削除対象のデータを通常利用に戻さないよう処理します。運営者による別のバックアップは作成しません。法令に基づく保存が必要な場合は、その範囲と期間に限定します。

Discord上のメッセージやチャンネル、管理者・利用者が書き出したファイルは別に管理されます。BOTの保管データを削除しても、これらの記録が一括で消えるとは限りません。Discord上の記録は該当サーバーの管理者へ、外部に書き出したファイルは保管者へ削除を依頼できます。

## 5. 外部サービス

本BOTはDiscord上で動作するアプリです。Discord側の情報の取り扱いは、[Discordプライバシーポリシー](https://discord.com/privacy)にも従います。

本BOTの常時運用とデータ保存には、Cloudflare, Inc.のCloudflare WorkersおよびDurable Objectsを使用します。操作を処理するため、第2項のうち実装済みの機能に必要なDiscord識別情報、権限情報、投稿・フォームの入力、チケット管理情報、藩士名簿、イベント設定・参加・抽選・ビンゴの情報、設定および操作記録を同社の基盤上で取り扱います。保存するBOTデータは暗号化し、サーバーごとに分離します。BOTトークンと暗号鍵は、アクセスを制限したCloudflare WorkersのSecretsに保存します。本文やトークンを含むアプリケーションログの保存は有効にしません。

関連する情報は、[Cloudflareプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)および[データベースの復旧履歴に関する公式説明](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/)を参照してください。新たな外部連携を追加する際は、提供開始前に提供元、取り扱うデータ、利用目的と関連ポリシーを本ページまたは連携の案内に明示します。

Embed Generator（message.style）と連携する場合にも、連携に必要な情報と送信先を事前に案内します。同サービスを直接利用する際は、[同サービスのプライバシーポリシー](https://message.style/privacy/)も確認してください。

## 6. 安全管理

機能に必要な権限だけを使用し、サーバーごとのアクセスを分離します。運営者の管理下で保存する情報は暗号化とアクセス制御により保護し、認証情報を投稿内容やログから分離します。これらの措置を実装してから、対象となる保存機能を提供します。

## 7. 確認・訂正・削除の依頼

BOT運営者が管理する自分の情報については、Discordユーザー **chimposs** へのダイレクトメッセージで確認・訂正・削除を依頼できます。直接連絡できない場合は、導入先サーバーの管理者を通じて運営者へ連絡してください。

対象を特定するため、DiscordユーザーID、対象サーバー、チケット番号や投稿URL等を必要な範囲で確認します。パスワードやBOTトークンの送付は求めません。確認後は速やかに対応し、原則30日以内に結果を案内します。法令上の保存義務や、運営者が管理していないデータがある場合は、対応可能な範囲と理由を説明します。

## 8. 変更

本方針を変更した場合は本ページの日付を更新します。収集情報、利用目的、外部送信先等の重要な変更は、対象機能を提供する前に案内します。
